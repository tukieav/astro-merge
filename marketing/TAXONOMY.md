## Rationale

Astro Merge is an immediate, score-driven drop-and-merge game with short runs,
physics placement and arcade pressure, so Arcade is the primary category.
Casual and Merge describe the discovery intent; Mobile, Relaxing, 2D, Mouse and
Physics are only used because each has a verified live CrazyGames route and is
directly supported by the build.

The submission must not use stale or invented portal labels. Terms such as
planets, space, combo and Stardust are accurate natural-language description
keywords, but not portal tags. No clone or IP framing is used.
